# PilulAmi

Landing page Next.js pour collecter les inscriptions à la liste d’attente de **PilulAmi** : rappels de médicaments pour un parent âgé, alertes pour l’aidant.

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000).

Les e-mails de la liste d’attente sont enregistrés dans `data/waitlist.json` (fichier ignoré par git).
